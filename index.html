Idles de Animación para Videojuegos

Maya · Unity · C# · Animación 3D

Proyecto enfocado en el estudio y desarrollo de animaciones tipo idle para personajes de videojuegos.

Se trabajó a partir de un modelo base proporcionado por la universidad, realizando el análisis de movimientos, tiempos y transiciones para lograr animaciones naturales como respiración y reposo.

Las animaciones fueron creadas en Maya, posteriormente horneadas (baking) e importadas a Unity, donde se implementaron mediante un sistema de estados controlado por programación en C#.

Se configuró el controlador de animaciones para asociar distintos estados a teclas del teclado, además de integrar colisiones mediante cápsulas para asegurar el desplazamiento correcto del personaje sobre el escenario sin atravesar el suelo.
